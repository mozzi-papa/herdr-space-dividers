# 사용법

## 실행 구조

Ghostty 같은 터미널 앱에서 수정한 Herdr 클라이언트가 기존 기본 로컬 Herdr 서버에 연결됩니다. 실제 셸·에이전트는 서버가 관리하고, 이 프로젝트는 화면 쪽 구분선과 분류 정보를 관리합니다.

현재 실행기는 `~/.config/herdr/config.toml`과 `~/.config/herdr/herdr.sock`을 사용합니다. 별도 설정 경로·이름 있는 세션·원격 머신 통합 목록을 위한 실행기는 포함하지 않습니다.

Homebrew 설치는 `herdr-dividers`를 실행해 주세요. 소스 빌드 설치는 저장소 폴더에서 `sh run.sh`를 실행합니다. 실행 중인 Herdr 안이라면 기본 설정의 `Ctrl+B`, `q`로 화면을 분리한 뒤 실행합니다. 새 서버를 자동으로 시작하거나 사용자 서버를 종료하지 않습니다.

## 구분선 만들기

1. 구분선을 넣을 위치 바로 위의 스페이스를 선택합니다.
2. `spaces` 목록 하단의 `div`를 클릭합니다.
3. 제목을 입력하고 Enter를 누릅니다. Esc는 취소입니다.

구분선은 최대 32개, 제목은 최대 60자입니다. 빈 제목은 생성하지 않습니다. 제목 위에는 빈 줄 한 줄을 두고, 소속 스페이스는 두 칸 들여씁니다. 사이드바가 너무 좁으면 버튼 겹침을 막기 위해 `div` 버튼이 숨겨집니다. 사이드바를 넓혀 주세요.

## 분류 소속과 드래그

스페이스의 이름이나 목록 순번 대신 **스페이스 ID**를 소속으로 저장합니다. 다른 공간을 추가·삭제해도 기존 분류가 밀리지 않습니다. 새 스페이스는 구분선 위의 미분류 영역에 나타납니다.

- 스페이스를 원하는 분류의 제목이나 스페이스 행으로 드래그하면 소속을 옮깁니다. 분류 안의 순서 이동은 Herdr의 기존 이동 동작과 함께 처리합니다.
- 스페이스를 첫 구분선 위쪽의 미분류 영역으로 옮기면 소속을 해제합니다.
- **구분선 제목을 드래그하면 분류 경계를 옮깁니다.** 이때 경계 양쪽 공간의 소속이 다시 정해집니다. 분류 전체를 통째로 옮기는 동작이 아닙니다.
- 목록 밖으로 놓으면 드롭을 취소합니다. 기존 worktree 자식은 기존 부모와 함께 다룹니다.

## 접기·펼치기와 숫자 이동

제목을 클릭하면 해당 분류를 접거나 펼칩니다. 제목 옆 숫자는 현재 표시 기준의 소속 수입니다. 접어도 내부 셸·에이전트·서버는 계속 실행됩니다. 접기는 작업 중지나 메모리 정리 기능이 아닙니다.

구분선은 숫자 이동 대상에서 제외합니다. 접힌 스페이스도 전체 이동 순서에 포함하며, 단축키로 선택하면 해당 분류가 펼쳐집니다. 숫자 순서는 화면의 분류 순서를 따릅니다.

### Ghostty에서 ⌘1~9 사용하기

터미널과 Herdr 양쪽의 키 전달 설정이 필요합니다. 다음은 검증 환경의 선택 설정 예시입니다. 자동으로 적용하지 않습니다.

Herdr 설정에 이미 `[keys]`가 있다면 그 안에 아래 키만 합쳐 주세요. 같은 표를 중복 선언하지 않습니다.

```toml
[keys]
switch_workspace = "cmd+1..9"
```

사용 중인 Ghostty 설정 파일에는 다음 바인딩을 사용합니다. 기존 동일 키 설정과 충돌하지 않게 합쳐 주세요. 이 바인딩을 적용하면 해당 키가 Herdr에 전달됩니다.

```ini
keybind = cmd+digit_1=csi:49;9u
keybind = cmd+digit_2=csi:50;9u
keybind = cmd+digit_3=csi:51;9u
keybind = cmd+digit_4=csi:52;9u
keybind = cmd+digit_5=csi:53;9u
keybind = cmd+digit_6=csi:54;9u
keybind = cmd+digit_7=csi:55;9u
keybind = cmd+digit_8=csi:56;9u
keybind = cmd+digit_9=csi:57;9u
```

설정 파일을 백업하고 각 앱의 설정 다시 읽기를 적용해 주세요. 다른 터미널이나 사용자의 키 설정은 별도 확인이 필요합니다.

## 우클릭 메뉴

| 대상 | 기능 |
|---|---|
| div 제목 | 이름 변경, 구분선 삭제, 구분선 편집 실행 취소 |
| 스페이스 | 기존 스페이스 메뉴, Finder에서 폴더 열기, 폴더 경로 복사 |

div 삭제는 구분선만 제거합니다. 스페이스·셸·에이전트를 닫지 않으며, 남은 구분선 위치에 따라 소속을 다시 구성합니다.

하단 `menu → 구분선 복구` 또는 div 우클릭의 편집 취소로 최근 편집을 최대 20회 되돌립니다. 기록은 현재 클라이언트의 메모리에만 보관합니다. 접속을 종료하면 사라지며, 서버의 스페이스 순서 변경을 되돌리는 기능은 포함하지 않습니다.

Finder 열기·경로 복사는 **우클릭한 스페이스의 작업 경로**를 사용합니다. Finder 열기는 로컬 폴더만 대상으로 합니다. 존재하지 않는 폴더는 오류로 안내합니다. 터미널 출력에 있는 모든 일반 경로를 자동으로 클릭 가능하게 만드는 기능은 포함하지 않습니다.

로컬 실행의 경로 복사는 맥 클립보드를 사용합니다. SSH 환경에서는 기존 터미널 클립보드 전송을 사용하므로 접속한 터미널의 허용 설정을 따릅니다.

## 저장과 다른 기기

제목·위치·소속·접기 상태는 기존 클라이언트 JSON에 자동 저장합니다.

```text
~/.local/state/herdr-dev/client-shell/local-*.json
```

`XDG_STATE_HOME`을 설정하면 그 위치를 사용하며, 연결하는 서버의 소켓 경로에 따라 파일을 구분합니다. 저장 실패 시 오류를 안내하고 화면의 설정은 메모리에 유지합니다. 저장 오류가 있으면 종료 전에 해결해 주세요.

같은 맥의 같은 계정에 SSH로 로그인하여 같은 수정본과 세션을 실행하면 같은 설정 경로를 사용할 수 있습니다. 다른 맥의 별도 클라이언트로 자동 동기화하지 않습니다. 동시 편집은 마지막 저장이 우선합니다. SSH·다중 기기의 실제 동작은 현재 배포 검증에 포함하지 않았습니다.

SSH로 접속한 맥에서 Finder 열기를 실행하면 **Herdr 클라이언트가 실행되는 맥**의 Finder를 실행합니다. 휴대폰이나 접속한 다른 기기의 파일 앱을 여는 기능이 아닙니다.
