# 검증 기록

## 검증 환경

- macOS / Apple Silicon M2 Max, 메모리 32GB
- Herdr 공식 소스 v0.9.5
- Rust 1.96.1, Zig 0.16.0, 디버그 빌드
- 실제 마우스 입력·재접속 검증은 별도 가상 터미널과 임시 서버 사용

기존 개발본에서 클라이언트 테스트 **391개 통과**, 수동 검사 **3개 제외**를 확인했습니다. 필수 분류·접기·편집 취소·드래그·폴더 메뉴 테스트 7개가 실제 통과하는지 업데이트 도구가 확인합니다.

## 확인 항목

- div 생성·이름 변경·이동·삭제가 새 셸·에이전트를 만들거나 기존 페인을 닫지 않는지 확인합니다.
- 스페이스 추가·삭제 후 소속 보존, 접기, 숫자 이동 시 펼치기와 스크롤을 확인합니다.
- JSON 저장과 새 클라이언트 프로세스의 재접속 복원을 확인합니다.
- div 편집 메뉴와 스페이스 폴더 메뉴가 분리되고, 우클릭 대상의 경로를 사용하는지 확인합니다.
- 별도 서버 검증 전후 스페이스·탭·페인·에이전트 개수와 페인 ID를 대조합니다.
- 패치·빌드·검증·백업 실패 시 현재 선택 유지, 실행 파일 선택 복구, 동시 업데이트 차단을 검사합니다.
- 소스 버전 불일치, 압축 경로 이탈·외부 링크, 필수 테스트 누락·무시를 거부하는지 검사합니다.

## 직접 재검증

```sh
python3 -m unittest discover -s tools -p 'test_update_custom.py' -v
sh -n update-custom.sh
sh -n run.sh
sh update-custom.sh 0.9.5
```

전체 명령은 공식 소스에 패치를 다시 적용하고 클라이언트 테스트·빌드·포맷·별도 터미널 검증을 실행합니다. 성공한 실행 파일만 선택합니다. 실제 결과는 해당 실행의 `update-logs/.../update.log`와 `releases/.../validation.json`에 기록됩니다.

로컬 로그는 개인 경로가 포함될 수 있어 이 배포본에 포함하지 않습니다. 날짜·버전·검사 범위만 문서에 정리합니다. 잘못된 소스 버전을 넣어 중단을 확인하는 검사는 새로운 Herdr 버전을 실제 빌드해 확인한 결과와 구분합니다.

## 현재 한계

다른 맥의 실제 SSH, 사용자 Ghostty 화면 전체 조작, Intel·Linux·Windows, 메모리 사용량 및 외부 보안 감사는 확인하지 않았습니다. 릴리스 빌드는 아래 2026-11-09 기록에서 확인했습니다. 미래 버전의 기능 유지 여부는 그 소스로 다시 검증해야 합니다.


## 공개용 패키지 최종 확인 — 2026-11-06

개인 개발 폴더와 별개인 배포 폴더에서, 로컬 원본 압축 파일을 복사하지 않고 공식 GitHub 소스를 새로 다운로드하여 검사했습니다. 변경된 Rust 파일 14개에 수정 고지가 추가된 공개용 패치를 사용했습니다.

- 업데이트 도구 검사 **14개 통과**, 실패 0개입니다. 기본 설치 경로에 공식 실행 파일이 없을 때 PATH를 사용하는 동작과 백업 디렉터리 권한도 검사했습니다.
- Herdr 클라이언트 테스트 **391개 통과**, 실패 0개, 기존 수동 검사 3개 제외입니다. 필수 기능 테스트 7개도 실제 통과했습니다.
- 새 실행 파일 빌드, Rust 포맷, 셸 문법, Python 컴파일 검사를 통과했습니다.
- 별도 가상 터미널에서 마우스 편집·접기·숫자 이동·저장·새 클라이언트 재접속·폴더 메뉴·경로 복사를 확인했습니다. 기존 ID와 개수를 유지했습니다.
- 배포 후보 파일 17개를 명시적으로 선정했습니다. 개인 개발 경로·알려진 개인 식별 정보·토큰과 개인 키 패턴을 검사했고 문서의 로컬 링크도 확인했습니다. 이 패턴 검사는 외부 보안 감사를 대신하지 않습니다.
- 원본 Apache 라이선스 사본의 일치, 패치 SHA-256, 적용된 변경 파일 14개의 수정 고지와 검증 기록을 대조했습니다.

검증은 로컬 배포 폴더를 대상으로 했습니다. 실제 공개 저장소를 다른 맥에서 새로 받아 설치하는 검증과 공개 GitHub 작업은 이 결과에 포함하지 않습니다.

## Homebrew 패키지 0.1.0 — 2026-11-09

Apple Silicon M2 Max, macOS 26.3.1, Rust 1.96.1, Zig 0.16.0, Homebrew 7.0.11에서 Herdr 0.9.5 기반 릴리스 패키지를 확인했습니다. macOS 최소 배포 대상은 15.0이며, macOS 15에서의 실행은 직접 확인하지 않았습니다.

- Python 도구 검사 **19개 통과**, 실패 0개입니다. 실행기 심볼릭 링크, 잘못된 인자·중첩 접속 거부, 릴리스 빌드 선택, 라이선스 수집과 압축 파일 소유자 정보를 검사했습니다.
- 릴리스 모드 클라이언트 테스트 **392개 통과**, 실패 0개, 기존 수동 검사 3개 제외입니다. 저장 경로 유지 검사를 포함한 필수 테스트 8개도 실제 통과했습니다. 릴리스 빌드와 Rust 포맷 검사를 통과했습니다.
- 배포 실행 파일로 별도 임시 서버·가상 터미널의 마우스 편집·접기·숫자 이동·저장·재접속·폴더 메뉴·경로 복사를 확인했습니다. 디버그 실행 파일이 저장한 제목·소속·접기 상태를 릴리스 실행 파일이 복원하는 검사도 통과했습니다.
- 실행 파일의 ad-hoc 서명 검증, 시스템 라이브러리 연결, 로컬 개인 경로·계정 값과 압축 파일 소유자 정보 검사를 통과했습니다. Developer ID 서명·Apple 공증은 수행하지 않았습니다.
- Rust 패키지 211개의 라이선스 고지와 vendored 소스·Zig·Rust 고지를 포함했습니다. 배포 crate에서 누락된 고지는 원본 커밋·SHA-256·선언 라이선스를 대조해 보완했습니다.
- 임시 로컬 tap의 `file://` 배포 파일로 Homebrew 설치·formula 테스트·버전·도움말·명령 링크와 설치 실행 파일 해시 일치를 확인했습니다. 공식 `herdr` 명령과 사용 중인 서버는 교체하지 않았습니다.

압축 파일은 약 8MB, Homebrew 설치 크기는 약 37MB입니다. 디스크 용량이며 메모리 측정값이 아닙니다. 실제 메모리·성능 벤치마크, 공개 GitHub 다운로드 URL을 통한 설치와 다른 맥의 설치는 이 로컬 검증에 포함하지 않습니다.

## 릴리스 도구 재검증

```sh
python3 -m unittest discover -s tools -p 'test_*.py' -v
sh -n bin/herdr-div
python3 tools/build_release.py
```

빌드 결과는 `dist/`의 압축 파일·`SHA256SUMS`·formula에 생성합니다. 압축 파일의 `share/herdr-space-dividers/build-info.json`에 버전·실행 파일과 소스·패치 해시·서명 방식·검증 환경을 기록합니다. 로컬 로그와 작업 경로는 배포하지 않습니다.

## 실행기 서버 시작 검증 — 2026-11-10

재부팅 직후 서버 프로세스는 없고 소켓 파일만 남은 상태에서 실행기가 세션을 잃지 않는지 확인했습니다. 실행 중인 사용자 서버와 겹치지 않도록 임시 HOME 폴더의 별도 공식 서버를 사용했습니다.

- Python 도구 검사 **21개 통과**, 실패 0개입니다. 소켓 파일만 남은 상태에서 공식 서버를 한 번만 시작하는지, 이미 응답하는 서버는 다시 시작하지 않는지, 공식 `herdr`가 없을 때 `command herdr` 안내를 표시하고 멈추는지 검사합니다.
- 임시 서버에 스페이스 2개를 만들고 저장된 뒤 서버를 강제 종료(SIGKILL)해 소켓 파일만 남긴 상태를 만들었습니다. 이 상태에서 `herdr-dividers`(릴리스 클라이언트)와 소스 빌드(디버그) 실행기를 각각 실행해 서버가 시작되고 스페이스 2개가 복원되는 것을 확인했습니다.
- 같은 방법으로 이전 0.1.0 실행기도 확인했습니다. 릴리스 클라이언트는 직접 서버를 시작해도 `~/.config/herdr`를 사용하므로 세션이 복원되었습니다. 세션이 복원되지 않은 사고는 디버그 빌드가 서버를 시작해 `~/.config/herdr-dev`를 사용했을 때만 재현되었습니다.
- 실제 맥 재부팅 후 `herdr`(소스 빌드 실행기)를 실행해 공식 서버가 시작되고 스페이스 11개와 구분선 2개(개발 5개, 개인 5개)가 복원되는 것을 확인했습니다. 서버는 공식 실행 파일로 시작되었습니다. `herdr-dividers`(Homebrew 실행기)의 실제 재부팅 확인은 포함하지 않습니다.
- 확인하지 않은 범위: 서버를 클라이언트가 시작한 뒤 클라이언트 종료 시의 서버 생존 시간, 다른 맥·macOS 버전.

## 공개 경로 설치 — 2026-11-11

공개된 `v0.1.1` 릴리스를 Homebrew 경로로 설치해 확인했습니다.

- `brew tap mozzi-papa/tap` 후 `brew install mozzi-papa/tap/herdr-space-dividers`로 0.1.1을 설치했습니다. 내려받은 파일의 SHA-256이 formula의 값과 일치했습니다.
- `herdr-dividers --version`이 `herdr-dividers 0.1.1 (herdr 0.9.5)`를 출력했습니다.
- Herdr 화면을 분리한 뒤 Herdr 밖에서 `herdr-dividers`를 실행했습니다. 스페이스 11개와 구분선 2개(개발 5개, 개인 5개)가 소스 빌드 실행기와 같게 표시되었습니다. 두 클라이언트는 같은 서버와 같은 구분선 설정 파일을 사용합니다.
- 확인하지 않은 범위: 재부팅 직후 `herdr-dividers` 단독 실행, 다른 맥·macOS 버전, 접기·펼치기 등 화면 조작의 릴리스 빌드 직접 확인.
