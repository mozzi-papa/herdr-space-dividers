# Herdr Space Dividers 0.1.3

버전 표시와 업데이트 알림을 추가한 릴리스입니다. Herdr 0.9.5를 기반으로 합니다.

## 변경 사항

- 실행 명령이 `herdr-div`로 짧아졌습니다. 기존 `herdr-dividers`도 같은 명령으로 계속 쓸 수 있습니다.
- 하단 `menu`에 현재 버전(`Herdr Space Dividers 0.1.3`)을 표시합니다.
- 실행할 때와 6시간마다 최신 정식 릴리스를 확인하고, 새 버전이 있으면 `menu` 옆에 ● 표시와 `업데이트 · 명령 복사`, `릴리스 노트 열기` 항목을 보여 줍니다. 공식 Herdr의 `update ready`와는 별개 항목입니다.
- 버전 항목을 누르면 바로 최신 버전을 확인해 `최신 버전입니다` 또는 `확인 실패`를 알려 줍니다.
- 자동 설치는 하지 않고 `brew upgrade mozzi-papa/tap/herdr-space-dividers` 명령만 복사합니다.
- 확인은 최신 버전 번호만 GitHub에서 조회하며 사용자 정보는 보내지 않습니다. `HERDR_DIVIDERS_NO_UPDATE_CHECK=1`로 자동 확인을 끌 수 있습니다.
- 확인 실패, 시험판·잘못된 태그, 이 저장소가 아닌 주소는 무시합니다.
- 구분선 색이 저장 파일에 기록되고 다시 실행해도 유지되는지 테스트로 보호합니다. 색을 모르는 이전 버전 클라이언트와 같은 설정 파일을 같이 쓰면 그쪽이 저장할 때 색이 지워지므로 `herdr-div` 하나만 사용해 주세요.

## 업데이트

```sh
brew upgrade mozzi-papa/tap/herdr-space-dividers
```
