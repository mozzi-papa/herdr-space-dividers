# Herdr Space Dividers 0.1.1

재부팅 직후 실행 문제를 보완한 패치 릴리스입니다. Herdr 0.9.5를 기반으로 합니다.

## 변경 사항

- 실행기가 서버 소켓 파일의 존재가 아니라 **서버의 실제 응답**으로 상태를 판단합니다. 재부팅 직후 소켓 파일만 남은 경우에도 정상적으로 동작합니다.
- 서버가 응답하지 않으면 공식 `herdr server`를 시작해 저장된 세션을 복원한 뒤 접속합니다. 이미 응답하는 서버는 종료하거나 재시작하지 않습니다.
- 공식 `herdr`를 찾지 못하면 `command herdr`로 순정 Herdr를 먼저 실행하라는 안내를 표시합니다.
- 문제가 생겼을 때 `command herdr`로 순정 Herdr를 실행하는 방법을 [README](https://github.com/mozzi-papa/herdr-space-dividers#문제가-생겼을-때-순정-herdr로-실행)에 정리했습니다.

기존 구분선·소속·접기 상태 파일은 그대로 사용합니다. 기능 변경은 없습니다.

## 업데이트

```sh
brew upgrade mozzi-papa/tap/herdr-space-dividers
```

## 검증과 고지

Python 도구 테스트 21개를 통과했습니다. 임시 HOME에서 서버를 강제 종료해 소켓 파일만 남긴 상태를 재현하고, 실행기가 서버를 시작해 세션 2개를 복원하는 것을 확인했습니다. 실제 맥 재부팅 후 `herdr` 실행으로 스페이스 11개와 구분선 2개가 복원되는 것을 확인했습니다. 자세한 범위는 [검증 기록](https://github.com/mozzi-papa/herdr-space-dividers/blob/main/docs/VERIFICATION.md)을 참고해 주세요.
