# Herdr Space Dividers 0.1.0

Apple Silicon용 첫 사전 빌드 패키지입니다. Herdr 0.9.5를 기반으로 합니다.

## 설치

처음 설치할 때 필요한 배포 저장소 등록과 설치를 아래 한 줄로 진행합니다.

```sh
brew tap mozzi-papa/tap && brew install mozzi-papa/tap/herdr-space-dividers
herdr-dividers
```

macOS 15 이상, Homebrew와 공식 Herdr의 기본 로컬 서버가 필요합니다. Herdr 안에서는 먼저 기본 설정의 `Ctrl+B`, `q`로 화면만 분리해 주세요. Rust·Zig·Python은 사용자 설치에 필요하지 않습니다.

## 포함된 기능

- 구분선 생성·이름 변경·삭제, 분류·접기·드래그·편집 취소를 제공합니다.
- 스페이스 우클릭으로 Finder 열기·폴더 경로 복사를 제공합니다.
- `herdr-dividers --version`, `herdr-dividers --help`와 Homebrew 업데이트를 제공합니다.
- 디버그·릴리스 빌드에서 기존 `herdr-dev/client-shell` 설정 경로를 함께 사용합니다. 기존 구분선·소속·접기 상태를 유지합니다.

기존 공식 명령·셸 시작 파일을 교체하지 않고 작업 서버를 자동 종료하지 않습니다. 구분선은 새 셸·에이전트를 만들지 않으며 숫자 이동 대상에서 제외합니다.

## 검증과 고지

M2 Max / macOS 26.3.1에서 릴리스 클라이언트 테스트 392개와 Python 도구 검사 19개를 통과했습니다. 임시 서버의 마우스·저장·재접속과 디버그 설정 복원을 확인했습니다. 로컬 배포 파일로 Homebrew 설치·formula 테스트를 확인했습니다.

첨부한 `SHA256SUMS`로 압축 파일을 대조할 수 있습니다. 패키지에 원본·의존성 라이선스와 빌드 정보를 포함합니다. 독립 도구·문서는 MIT, Herdr 기반 패치는 Apache-2.0입니다.

이 파일은 Herdr의 비공식 수정본입니다. Developer ID 서명·Apple 공증은 받지 않았습니다. macOS 15에서의 직접 실행, 다른 맥·SSH·Intel·다른 OS, 메모리 벤치마크와 미래 Herdr 호환성은 별도 확인이 필요합니다. 공개 다운로드 경로를 통한 설치 결과는 공개 후 검증 기록에 추가합니다.
